# TC-004: 默认骨架测试（无模板、无DDD）

**测试目标**：验证无模板、无 DDD 注入时，创建基础骨架

---

## 提示词（发送给 Planner）

```
你是编码项目架构师。请为以下需求创建开发计划：

需求：做一个简单的待办事项 CLI

技术要求：
- 版本号：v0.0.1

请创建项目骨架、dev-plan.md、design.md、feature-spec.md。
```

---

## 预期结果

**项目结构**：
```
{project}/
├── docs/
│   ├── dev-plan.md          # 应包含 "使用模板：无模板" 或留空
│   ├── design.md
│   └── feature-spec.md
├── src/                     ✅ 基础目录（无子目录）
├── tests/
└── tests/reports/
```

**dev-plan.md 检查点**：
- [ ] "使用模板" 字段为空或标注"无模板"
- [ ] 项目类型：纯后端（CLI）
- [ ] 任务列表包含项目骨架任务

**目录检查**：
- [ ] src/ 存在（且无四层子目录）
- [ ] tests/ 存在
- [ ] tests/reports/ 存在

---

## 验证命令

```bash
# 检查目录结构
ls -la {project}/src/

# 检查 dev-plan.md 模板字段
grep "使用模板" {project}/docs/dev-plan.md

# 验证无四层目录
[ ! -d {project}/src/domain ] && echo "✅ 无 DDD 目录" || echo "❌ 不应有 DDD 目录"
```
