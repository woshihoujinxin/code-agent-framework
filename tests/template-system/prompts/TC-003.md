# TC-003: DDD 注入无模板测试

**测试目标**：验证注入 `方法论：DDD` 但无模板参数时，创建四层 DDD 骨架

---

## 提示词（发送给 Planner）

```
你是编码项目架构师。请为以下需求创建开发计划：

需求：做一个订单管理系统

技术要求：
- 方法论：DDD
- 版本号：v0.0.1

请创建项目骨架、dev-plan.md、design.md、feature-spec.md。
```

---

## 预期结果

**项目结构**：
```
{project}/
├── docs/
│   ├── dev-plan.md          # 应包含 "使用模板：无模板" 或留空
│   ├── design.md
│   └── feature-spec.md
└── src/
    ├── domain/              ✅ DDD 四层目录（手工创建）
    ├── application/
    ├── interface/
    └── infrastructure/
```

**dev-plan.md 检查点**：
- [ ] "使用模板" 字段为空或标注"无模板"
- [ ] 项目类型：纯后端
- [ ] 任务列表包含项目骨架任务

**目录检查**：
- [ ] src/domain/ 存在
- [ ] src/application/ 存在
- [ ] src/interface/ 存在
- [ ] src/infrastructure/ 存在

---

# 检查目录结构
